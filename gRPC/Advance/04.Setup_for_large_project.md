## Chapter 1 — The Architecture We Are Building

Before touching a single file, you need a map. A large-scale microservices project without a clear service topology turns into a spaghetti of ad-hoc connections that nobody can reason about six months later. The architecture here follows a pattern used at companies like Uber, Netflix, and Lyft: every service exposes a gRPC server, every service has generated client stubs for every other service it needs to talk to, and all cross-service communication flows through an API Gateway at the edge.

```
                          Internet / Mobile / Browser
                                     │
                          ┌──────────▼──────────┐
                          │     API Gateway     │  :8080  (REST → gRPC translation)
                          │  (grpc-gateway)     │
                          └──────────┬──────────┘
                                     │  internal gRPC calls
          ┌──────────────────────────┼──────────────────────────┐
          │                          │                          │
  ┌───────▼──────┐          ┌────────▼───────┐         ┌────────▼────────┐
  │ UserService  │          │  OrderService  │         │ ProductService  │
  │   :50051     │          │    :50052      │         │    :50053       │
  └───────┬──────┘          └───────┬────────┘         └────────┬────────┘
          │                         │                           │
          │              ┌──────────┼────────────┐              │
          │              │          │            │              │
  ┌───────▼──────┐  ┌────▼──────┐  │     ┌───────▼──────┐       │
  │  AuthService │  │InventorySvc│ │     │PaymentService│       │
  │   :50054     │  │  :50055   │  │     │   :50056     │       │
  └──────────────┘  └───────────┘  │     └──────────────┘       │
                                   │                            │
          ┌────────────────────────┼────────────────────────────┘
          │                        │
  ┌───────▼──────┐        ┌────────▼───────┐
  │NotificationSvc│       │  SearchService │
  │   :50057     │        │    :50058      │
  └──────────────┘        └────────────────┘
          │
  ┌───────▼──────┐        ┌────────────────┐
  │  AuditService│        │ReportingService│
  │   :50059     │        │    :50060      │
  └──────────────┘        └────────────────┘
```

The important rule: **services never share a database**. They own their data and expose it only through their gRPC interface. OrderService never queries UserService's database directly — it calls `UserService.GetUser()` and gets a typed response. This is the foundational discipline that makes microservices actually work.

## Chapter 3 — The Proto Files (Service Contracts)

Each service gets its own `.proto` file. They are intentionally kept small — each one owns only the messages and services that belong to that bounded context. Services reference each other's message types by importing the right proto file.

### 3.1 — User Service Proto

```protobuf
// proto/user/user.proto
syntax = "proto3";

package user.v1;
option go_package = "grpc-platform/pb/userpb";

// ── Messages ──────────────────────────────────────────────────────────

message User {
  string id         = 1;   // field 1-15 are 1-byte tags on the wire
  string name       = 2;
  string email      = 3;
  string role       = 4;
  int64  created_at = 5;   // unix timestamp
}

message GetUserRequest {
  string user_id = 1;
}

message GetUserResponse {
  User user = 1;
}

message CreateUserRequest {
  string name     = 1;
  string email    = 2;
  string password = 3;
}

message CreateUserResponse {
  User   user    = 1;
  string message = 2;
}

message ListUsersRequest {
  int32 page      = 1;
  int32 page_size = 2;
}

message ListUsersResponse {
  repeated User users = 1;
  int32 total         = 2;
}

// ── Service ────────────────────────────────────────────────────────────

service UserService {
  rpc GetUser    (GetUserRequest)    returns (GetUserResponse);
  rpc CreateUser (CreateUserRequest) returns (CreateUserResponse);
  rpc ListUsers  (ListUsersRequest)  returns (ListUsersResponse);
}
```

## Chapter 4 — The Proto Generation Script

Managing `protoc` invocations manually across 10 services is error-prone. One shell script regenerates everything from scratch.

```bash
#!/usr/bin/env bash
# scripts/gen-proto.sh
# Run from the project root: bash scripts/gen-proto.sh

set -e   # exit immediately on any error

PROTO_DIR="./proto"
OUT_DIR="."

# Verify tools are installed before doing any work
echo "→ Checking tools..."
command -v protoc           >/dev/null 2>&1 || { echo "ERROR: protoc not found. Run: brew install protobuf"; exit 1; }
command -v protoc-gen-go    >/dev/null 2>&1 || { echo "ERROR: protoc-gen-go not found. Run: go install google.golang.org/protobuf/cmd/protoc-gen-go@latest"; exit 1; }
command -v protoc-gen-go-grpc >/dev/null 2>&1 || { echo "ERROR: protoc-gen-go-grpc not found. Run: go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest"; exit 1; }

echo "→ Cleaning old generated files..."
find ./pb -name "*.go" -delete 2>/dev/null || true

echo "→ Generating proto files..."

# Loop through every .proto file in every subdirectory of proto/
for proto_file in $(find $PROTO_DIR -name "*.proto"); do
  echo "   compiling: $proto_file"
  protoc \
    --proto_path=$PROTO_DIR \
    --go_out=$OUT_DIR \
    --go_opt=paths=source_relative \
    --go-grpc_out=$OUT_DIR \
    --go-grpc_opt=paths=source_relative \
    $proto_file
done

echo "✓ Proto generation complete"
echo "  Generated files:"
find ./pb -name "*.go" | sort
```

Run it once, and all `pb/` directories are populated:

```bash
# Make it executable, then run it
chmod +x scripts/gen-proto.sh
bash scripts/gen-proto.sh

# Output:
# → Checking tools...
# → Cleaning old generated files...
# → Generating proto files...
#    compiling: ./proto/user/user.proto
#    compiling: ./proto/order/order.proto
#    compiling: ./proto/auth/auth.proto
#    ...
# ✓ Proto generation complete
```

## Chapter 5 — The Shared Interceptor Library

This is where the best practices live. Every service in the platform imports these interceptors from `shared/interceptors/`. This means logging, authentication, tracing, and panic recovery are implemented once and applied consistently everywhere — not copied and pasted across 10 services.

### 5.1 — Logging Interceptor

```go
// shared/interceptors/logging.go
package interceptors

import (
    "context"
    "time"

    "go.uber.org/zap"
    "google.golang.org/grpc"
    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/status"
)

// UnaryLogging returns a server-side unary interceptor that logs every RPC call.
// It records the method name, duration, and whether it succeeded or failed.
// Attach it with: grpc.ChainUnaryInterceptor(interceptors.UnaryLogging(logger), ...)
func UnaryLogging(logger *zap.Logger) grpc.UnaryServerInterceptor {
    return func(
        ctx context.Context,
        req interface{},
        info *grpc.UnaryServerInfo,
        handler grpc.UnaryHandler,
    ) (interface{}, error) {
        start := time.Now()

        // Call the actual handler
        resp, err := handler(ctx, req)

        duration := time.Since(start)
        code := codes.OK
        if err != nil {
            code = status.Code(err)
        }

        // Structured logging — every field is queryable in your log aggregator
        logger.Info("gRPC unary call",
            zap.String("method",   info.FullMethod),
            zap.Duration("duration", duration),
            zap.String("code",     code.String()),
            zap.Error(err),
        )

        return resp, err
    }
}

// StreamLogging does the same for streaming RPCs.
func StreamLogging(logger *zap.Logger) grpc.StreamServerInterceptor {
    return func(
        srv interface{},
        ss grpc.ServerStream,
        info *grpc.StreamServerInfo,
        handler grpc.StreamHandler,
    ) error {
        start := time.Now()
        err := handler(srv, ss)
        logger.Info("gRPC stream call",
            zap.String("method",   info.FullMethod),
            zap.Duration("duration", time.Since(start)),
            zap.Bool("client_stream", info.IsClientStream),
            zap.Bool("server_stream", info.IsServerStream),
            zap.Error(err),
        )
        return err
    }
}
```

### 5.2 — Auth Interceptor (calls AuthService internally)

```go
// shared/interceptors/auth.go
package interceptors

import (
    "context"

    "google.golang.org/grpc"
    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/metadata"
    "google.golang.org/grpc/status"

    authpb "grpc-platform/pb/authpb"
)

// publicMethods lists RPC paths that do NOT require authentication.
// Login, register, and health checks are public; everything else is protected.
var publicMethods = map[string]bool{
    "/auth.v1.AuthService/GenerateToken": true,
    "/user.v1.UserService/CreateUser":    true,
    "/grpc.health.v1.Health/Check":       true,
}

// UnaryAuth returns an interceptor that validates JWT tokens on every
// incoming request by calling the AuthService. It injects the validated
// user_id and role into the context so handlers can access them without
// repeating the validation logic.
func UnaryAuth(authClient authpb.AuthServiceClient) grpc.UnaryServerInterceptor {
    return func(
        ctx context.Context,
        req interface{},
        info *grpc.UnaryServerInfo,
        handler grpc.UnaryHandler,
    ) (interface{}, error) {

        // Skip auth for public methods
        if publicMethods[info.FullMethod] {
            return handler(ctx, req)
        }

        // Extract the Authorization metadata (equivalent to HTTP headers in gRPC)
        md, ok := metadata.FromIncomingContext(ctx)
        if !ok {
            return nil, status.Error(codes.Unauthenticated, "missing metadata")
        }

        tokens := md["authorization"]
        if len(tokens) == 0 {
            return nil, status.Error(codes.Unauthenticated, "missing authorization token")
        }

        token := tokens[0]
        // Strip "Bearer " prefix if present
        if len(token) > 7 && token[:7] == "Bearer " {
            token = token[7:]
        }

        // Call AuthService to validate the token
        // This is an internal gRPC call, not an HTTP request
        resp, err := authClient.ValidateToken(ctx, &authpb.ValidateTokenRequest{
            Token: token,
        })
        if err != nil {
            return nil, status.Error(codes.Unauthenticated, "token validation failed")
        }
        if !resp.Valid {
            return nil, status.Error(codes.Unauthenticated, "invalid or expired token")
        }

        // Inject user_id and role into context — handlers read from here
        ctx = context.WithValue(ctx, contextKeyUserID, resp.UserId)
        ctx = context.WithValue(ctx, contextKeyRole,   resp.Role)

        return handler(ctx, req)
    }
}

// Context key types — using typed keys prevents collision with other packages
type contextKey string

const (
    contextKeyUserID contextKey = "user_id"
    contextKeyRole   contextKey = "role"
)

// UserIDFromContext extracts the authenticated user ID from the context.
// Call this from any handler that needs to know who is making the request.
func UserIDFromContext(ctx context.Context) (string, bool) {
    userID, ok := ctx.Value(contextKeyUserID).(string)
    return userID, ok
}

// RoleFromContext extracts the authenticated user's role from the context.
func RoleFromContext(ctx context.Context) (string, bool) {
    role, ok := ctx.Value(contextKeyRole).(string)
    return role, ok
}
```

### 5.3 — Recovery Interceptor (panic protection)

```go
// shared/interceptors/recovery.go
package interceptors

import (
    "context"
    "runtime/debug"

    "go.uber.org/zap"
    "google.golang.org/grpc"
    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/status"
)

// UnaryRecovery catches any panic inside a handler and converts it into
// a proper gRPC Internal error rather than crashing the entire server process.
// In production, one bad request should never take down the whole service.
func UnaryRecovery(logger *zap.Logger) grpc.UnaryServerInterceptor {
    return func(
        ctx context.Context,
        req interface{},
        info *grpc.UnaryServerInfo,
        handler grpc.UnaryHandler,
    ) (resp interface{}, err error) {
        // defer+recover must be a named return to catch the panic
        defer func() {
            if r := recover(); r != nil {
                logger.Error("panic recovered in gRPC handler",
                    zap.String("method", info.FullMethod),
                    zap.Any("panic", r),
                    zap.ByteString("stack", debug.Stack()),
                )
                err = status.Errorf(codes.Internal, "internal server error")
            }
        }()
        return handler(ctx, req)
    }
}
```

### 5.4 — Rate Limit Interceptor (per-method, per-user)

```go
// shared/interceptors/ratelimit.go
package interceptors

import (
    "context"
    "sync"

    "golang.org/x/time/rate"
    "google.golang.org/grpc"
    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/status"
)

// rateLimiter holds a token-bucket limiter per unique key (e.g. user_id).
// Each user gets their own rate limit bucket so one heavy user cannot
// starve all other users of capacity.
type rateLimiter struct {
    mu       sync.Mutex
    limiters map[string]*rate.Limiter
    rps      rate.Limit  // requests per second
    burst    int          // burst size
}

func newRateLimiter(rps float64, burst int) *rateLimiter {
    return &rateLimiter{
        limiters: make(map[string]*rate.Limiter),
        rps:      rate.Limit(rps),
        burst:    burst,
    }
}

func (rl *rateLimiter) get(key string) *rate.Limiter {
    rl.mu.Lock()
    defer rl.mu.Unlock()
    l, exists := rl.limiters[key]
    if !exists {
        l = rate.NewLimiter(rl.rps, rl.burst)
        rl.limiters[key] = l
    }
    return l
}

// UnaryRateLimit returns an interceptor that limits each user to `rps` req/sec
// with a burst allowance of `burst` requests. If the user is not authenticated,
// it falls back to limiting by IP (extracted from peer metadata).
func UnaryRateLimit(rps float64, burst int) grpc.UnaryServerInterceptor {
    rl := newRateLimiter(rps, burst)

    return func(
        ctx context.Context,
        req interface{},
        info *grpc.UnaryServerInfo,
        handler grpc.UnaryHandler,
    ) (interface{}, error) {

        // Use user_id as the rate limit key if authenticated, otherwise "anonymous"
        key, ok := UserIDFromContext(ctx)
        if !ok {
            key = "anonymous"
        }

        limiter := rl.get(key)
        if !limiter.Allow() {
            return nil, status.Errorf(codes.ResourceExhausted,
                "rate limit exceeded: max %.0f req/s", float64(rl.rps))
        }

        return handler(ctx, req)
    }
}
```

## Chapter 6 — Service Connection Manager (Client Pool)

In a large-scale setup, each service needs to connect to multiple other services. Naively creating a new `grpc.Dial()` connection every time a request comes in is catastrophically expensive — each dial involves a TCP handshake, TLS negotiation, and HTTP/2 connection setup. The right pattern is to create one persistent connection per target service at startup and reuse it for the lifetime of the process.

```go
// shared/config/connections.go
package config

import (
    "fmt"
    "sync"
    "time"

    "google.golang.org/grpc"
    "google.golang.org/grpc/backoff"
    "google.golang.org/grpc/credentials/insecure"
    "google.golang.org/grpc/keepalive"
)

// ServiceEndpoints holds the address of every service.
// In production these come from environment variables or a service mesh.
// With Kubernetes, you use the DNS name (user-service.default.svc.cluster.local).
type ServiceEndpoints struct {
    UserService         string
    OrderService        string
    PaymentService      string
    ProductService      string
    InventoryService    string
    NotificationService string
    AuthService         string
    SearchService       string
    AuditService        string
    ReportingService    string
}

// ConnectionManager holds one persistent gRPC connection per target service.
// It is safe to share across goroutines — gRPC connections are multiplexed
// over HTTP/2, so one connection handles thousands of concurrent RPCs.
type ConnectionManager struct {
    mu   sync.RWMutex
    pool map[string]*grpc.ClientConn
}

var manager *ConnectionManager
var once sync.Once

// GetConnectionManager returns the singleton connection manager.
func GetConnectionManager() *ConnectionManager {
    once.Do(func() {
        manager = &ConnectionManager{
            pool: make(map[string]*grpc.ClientConn),
        }
    })
    return manager
}

// Dial creates (or returns an existing) gRPC connection to the target address.
// All connections are configured with:
//   - Retry with exponential backoff
//   - Keepalive pings to detect dead connections
//   - Wait-for-ready semantics (client waits for server to come up)
func (cm *ConnectionManager) Dial(target string) (*grpc.ClientConn, error) {
    cm.mu.RLock()
    if conn, ok := cm.pool[target]; ok {
        cm.mu.RUnlock()
        return conn, nil
    }
    cm.mu.RUnlock()

    cm.mu.Lock()
    defer cm.mu.Unlock()

    // Double-check after acquiring write lock
    if conn, ok := cm.pool[target]; ok {
        return conn, nil
    }

    conn, err := grpc.Dial(
        target,

        // In production: replace with TLS credentials
        // grpc.WithTransportCredentials(credentials.NewTLS(tlsConfig))
        grpc.WithTransportCredentials(insecure.NewCredentials()),

        // Wait for the server to be ready before returning the connection.
        // Without this, the first RPC call blocks instead of Dial.
        grpc.WithBlock(),
        grpc.WithTimeout(10*time.Second),

        // Retry policy with exponential backoff.
        // If the target service is temporarily down, requests retry automatically.
        grpc.WithConnectParams(grpc.ConnectParams{
            Backoff: backoff.Config{
                BaseDelay:  100 * time.Millisecond,
                Multiplier: 1.6,
                Jitter:     0.2,
                MaxDelay:   10 * time.Second,
            },
            MinConnectTimeout: 5 * time.Second,
        }),

        // Keepalive: send a ping every 30s. If no response in 10s, close the connection.
        // This catches dead connections that the OS hasn't noticed yet
        // (e.g., a server process was killed without closing the TCP socket).
        grpc.WithKeepaliveParams(keepalive.ClientParameters{
            Time:                30 * time.Second,
            Timeout:             10 * time.Second,
            PermitWithoutStream: true,
        }),
    )
    if err != nil {
        return nil, fmt.Errorf("failed to connect to %s: %w", target, err)
    }

    cm.pool[target] = conn
    return conn, nil
}

// Close gracefully shuts down all connections.
// Call this on process shutdown to drain in-flight requests.
func (cm *ConnectionManager) Close() {
    cm.mu.Lock()
    defer cm.mu.Unlock()
    for target, conn := range cm.pool {
        conn.Close()
        delete(cm.pool, target)
    }
}
```

## Chapter 7 — Order Service (A Service That Talks to Multiple Other Services)

The Order Service is the most complex one in this architecture — it needs to call the User Service (verify the user exists), the Product Service (verify products exist and get prices), the Inventory Service (decrement stock), the Payment Service (charge the user), and the Notification Service (send confirmation). This is exactly the pattern of one service fanning out to many others.

### 7.1 — Client Wiring (`services/order-service/clients.go`)

```go
// services/order-service/clients.go
package main

import (
    "fmt"
    "os"

    authpb         "grpc-platform/pb/authpb"
    inventorypb    "grpc-platform/pb/inventorypb"
    notificationpb "grpc-platform/pb/notificationpb"
    paymentpb      "grpc-platform/pb/paymentpb"
    productpb      "grpc-platform/pb/productpb"
    userpb         "grpc-platform/pb/userpb"

    "grpc-platform/shared/config"
)

// ServiceClients bundles all outbound gRPC clients the OrderService needs.
// This is created once at startup and passed into every handler via dependency injection.
type ServiceClients struct {
    User         userpb.UserServiceClient
    Product      productpb.ProductServiceClient
    Inventory    inventorypb.InventoryServiceClient
    Payment      paymentpb.PaymentServiceClient
    Notification notificationpb.NotificationServiceClient
    Auth         authpb.AuthServiceClient
}

// NewServiceClients dials every dependency and returns the bundle.
// If any connection fails at startup, the whole service refuses to start —
// better to fail fast here than to crash on the first real request.
func NewServiceClients() (*ServiceClients, error) {
    cm := config.GetConnectionManager()

    // Addresses come from environment variables.
    // In Kubernetes these are set via a ConfigMap or service DNS names.
    endpoints := map[string]string{
        "user":         getEnv("USER_SERVICE_ADDR",         "localhost:50051"),
        "product":      getEnv("PRODUCT_SERVICE_ADDR",      "localhost:50053"),
        "inventory":    getEnv("INVENTORY_SERVICE_ADDR",    "localhost:50055"),
        "payment":      getEnv("PAYMENT_SERVICE_ADDR",      "localhost:50056"),
        "notification": getEnv("NOTIFICATION_SERVICE_ADDR", "localhost:50057"),
        "auth":         getEnv("AUTH_SERVICE_ADDR",         "localhost:50054"),
    }

    conns := make(map[string]interface{})
    for name, addr := range endpoints {
        conn, err := cm.Dial(addr)
        if err != nil {
            return nil, fmt.Errorf("order-service: failed to connect to %s at %s: %w", name, addr, err)
        }
        conns[name] = conn
    }

    // Import the grpc.ClientConn from the map and build typed clients.
    // Each NewXxxServiceClient call is generated code from protoc.
    return &ServiceClients{
        User:         userpb.NewUserServiceClient(conns["user"].(*grpc.ClientConn)),
        Product:      productpb.NewProductServiceClient(conns["product"].(*grpc.ClientConn)),
        Inventory:    inventorypb.NewInventoryServiceClient(conns["inventory"].(*grpc.ClientConn)),
        Payment:      paymentpb.NewPaymentServiceClient(conns["payment"].(*grpc.ClientConn)),
        Notification: notificationpb.NewNotificationServiceClient(conns["notification"].(*grpc.ClientConn)),
        Auth:         authpb.NewAuthServiceClient(conns["auth"].(*grpc.ClientConn)),
    }, nil
}

func getEnv(key, fallback string) string {
    if v := os.Getenv(key); v != "" {
        return v
    }
    return fallback
}
```

### 7.2 — Order Handler (fan-out to multiple services)

```go
// services/order-service/handler.go
package main

import (
    "context"
    "fmt"
    "time"

    "google.golang.org/grpc/codes"
    "google.golang.org/grpc/status"

    inventorypb    "grpc-platform/pb/inventorypb"
    notificationpb "grpc-platform/pb/notificationpb"
    orderpb        "grpc-platform/pb/orderpb"
    paymentpb      "grpc-platform/pb/paymentpb"
    productpb      "grpc-platform/pb/productpb"
    userpb         "grpc-platform/pb/userpb"
    "grpc-platform/shared/interceptors"
)

// OrderHandler implements the OrderServiceServer interface generated from order.proto.
// It holds references to all outbound service clients via dependency injection.
type OrderHandler struct {
    orderpb.UnimplementedOrderServiceServer
    clients *ServiceClients
    repo    OrderRepository
}

// CreateOrder is the most complex handler — it fans out to 5 other services
// in a specific sequence, and if any step fails, it must compensate
// (cancel what was already done). This is the Saga pattern.
func (h *OrderHandler) CreateOrder(
    ctx context.Context,
    req *orderpb.CreateOrderRequest,
) (*orderpb.CreateOrderResponse, error) {

    // Extract the calling user's ID from the context (set by the auth interceptor)
    callerID, ok := interceptors.UserIDFromContext(ctx)
    if !ok {
        return nil, status.Error(codes.Unauthenticated, "not authenticated")
    }

    // Requests to downstream services should use the same context so the
    // deadline/cancellation propagates. If the client cancels the request,
    // we don't want to keep charging the payment service.
    //
    // Add a child timeout: even if the parent context has no deadline,
    // we impose our own. CreateOrder should never take more than 10 seconds.
    ctx, cancel := context.WithTimeout(ctx, 10*time.Second)
    defer cancel()

    // ── STEP 1: Verify the user exists ──────────────────────────────────
    userResp, err := h.clients.User.GetUser(ctx, &userpb.GetUserRequest{
        UserId: req.UserId,
    })
    if err != nil {
        return nil, fmt.Errorf("order: GetUser failed: %w", err)
    }
    _ = userResp // use email for notification later

    // ── STEP 2: Validate every product and calculate total ───────────────
    var totalAmount float64
    validatedItems := make([]*orderpb.OrderItem, 0, len(req.Items))

    for _, item := range req.Items {
        prodResp, err := h.clients.Product.GetProduct(ctx, &productpb.GetProductRequest{
            ProductId: item.ProductId,
        })
        if err != nil {
            return nil, status.Errorf(codes.NotFound, "product %s not found", item.ProductId)
        }

        validatedItems = append(validatedItems, &orderpb.OrderItem{
            ProductId: item.ProductId,
            Quantity:  item.Quantity,
            UnitPrice: prodResp.Product.Price,
        })
        totalAmount += prodResp.Product.Price * float64(item.Quantity)
    }

    // ── STEP 3: Reserve inventory ────────────────────────────────────────
    // We attempt to reserve stock before charging. If payment fails, we
    // release the reservation (compensating transaction).
    reservationID := ""
    for _, item := range validatedItems {
        reserveResp, err := h.clients.Inventory.ReserveStock(ctx, &inventorypb.ReserveStockRequest{
            ProductId: item.ProductId,
            Quantity:  item.Quantity,
        })
        if err != nil {
            return nil, status.Errorf(codes.FailedPrecondition,
                "insufficient stock for product %s", item.ProductId)
        }
        reservationID = reserveResp.ReservationId
    }

    // ── STEP 4: Process payment ──────────────────────────────────────────
    payResp, err := h.clients.Payment.ProcessPayment(ctx, &paymentpb.ProcessPaymentRequest{
        UserId:        req.UserId,
        Amount:        totalAmount,
        ReservationId: reservationID,
    })
    if err != nil {
        // COMPENSATING TRANSACTION: payment failed, release inventory reservation
        _, _ = h.clients.Inventory.ReleaseReservation(ctx, &inventorypb.ReleaseReservationRequest{
            ReservationId: reservationID,
        })
        return nil, status.Errorf(codes.Internal, "payment failed: %v", err)
    }

    // ── STEP 5: Persist the order ────────────────────────────────────────
    order, err := h.repo.CreateOrder(ctx, &CreateOrderInput{
        UserID:        req.UserId,
        Items:         validatedItems,
        Total:         totalAmount,
        PaymentID:     payResp.PaymentId,
        ReservationID: reservationID,
    })
    if err != nil {
        return nil, status.Error(codes.Internal, "failed to save order")
    }

    // ── STEP 6: Send confirmation notification (non-blocking) ────────────
    // We send the notification in a goroutine because its failure should NOT
    // cause the entire CreateOrder to fail from the customer's perspective.
    // The order has been created and paid — a notification failure is a
    // degraded-but-acceptable outcome.
    go func() {
        // Use a fresh context here — the request context will be cancelled
        // after CreateOrder returns, which would cancel the notification call too.
        notifCtx, notifCancel := context.WithTimeout(context.Background(), 5*time.Second)
        defer notifCancel()

        _, err := h.clients.Notification.SendNotification(notifCtx, &notificationpb.SendNotificationRequest{
            UserId:  req.UserId,
            Type:    notificationpb.NotificationType_NOTIFICATION_TYPE_EMAIL,
            Subject: "Order Confirmed",
            Body:    fmt.Sprintf("Your order %s has been confirmed. Total: $%.2f", order.ID, totalAmount),
        })
        if err != nil {
            // Log the error but don't propagate it
            // In production: push to a retry queue or dead-letter queue
            _ = err
        }
    }()

    // ── STEP 7: Attach authenticated caller info to the audit trail ──────
    // Log who placed this order for compliance/audit purposes
    _ = callerID // used by audit service in real implementation

    return &orderpb.CreateOrderResponse{
        Order:   order,
        Message: "order created successfully",
    }, nil
}

// TrackOrder implements server-side streaming — the client subscribes once
// and the server pushes status updates as the order moves through its lifecycle.
func (h *OrderHandler) TrackOrder(
    req *orderpb.TrackOrderRequest,
    stream orderpb.OrderService_TrackOrderServer,
) error {
    ctx := stream.Context()

    // In production: subscribe to a message queue (Kafka/RabbitMQ) for order events
    // Here we simulate periodic status updates
    statuses := []orderpb.OrderStatus{
        orderpb.OrderStatus_ORDER_STATUS_CONFIRMED,
        orderpb.OrderStatus_ORDER_STATUS_SHIPPED,
        orderpb.OrderStatus_ORDER_STATUS_DELIVERED,
    }
    messages := []string{"Order confirmed", "Order shipped", "Order delivered"}

    for i, s := range statuses {
        // Check if the client has disconnected — if so, stop the stream
        select {
        case <-ctx.Done():
            return status.Error(codes.Canceled, "client disconnected")
        case <-time.After(2 * time.Second): // simulate processing time
        }

        update := &orderpb.OrderStatusUpdate{
            OrderId:   req.OrderId,
            Status:    s,
            Message:   messages[i],
            Timestamp: time.Now().Unix(),
        }

        // Send each update to the client as it happens
        if err := stream.Send(update); err != nil {
            return status.Errorf(codes.Internal, "failed to send update: %v", err)
        }
    }
    return nil
}
```

### 7.3 — Order Service Main (`services/order-service/main.go`)

```go
// services/order-service/main.go
package main

import (
    "net"
    "os"
    "os/signal"
    "syscall"
    "time"

    "go.uber.org/zap"
    "google.golang.org/grpc"
    "google.golang.org/grpc/health"
    "google.golang.org/grpc/health/grpc_health_v1"
    "google.golang.org/grpc/keepalive"
    "google.golang.org/grpc/reflection"

    orderpb "grpc-platform/pb/orderpb"
    "grpc-platform/shared/config"
    "grpc-platform/shared/interceptors"
)

func main() {
    // ── Logger ────────────────────────────────────────────────────────────
    logger, _ := zap.NewProduction()
    defer logger.Sync()

    // ── Connect to downstream services ────────────────────────────────────
    clients, err := NewServiceClients()
    if err != nil {
        logger.Fatal("failed to connect to downstream services", zap.Error(err))
    }
    defer config.GetConnectionManager().Close()

    // ── Build gRPC server with interceptor chain ──────────────────────────
    // Interceptors run in order: Recovery → Logging → RateLimit → Auth
    // Recovery is always outermost so it catches panics in all other interceptors too.
    grpcServer := grpc.NewServer(
        // Server-side keepalive: disconnect idle clients after 2 minutes
        // This prevents resource leaks from clients that disappear without closing
        grpc.KeepaliveParams(keepalive.ServerParameters{
            MaxConnectionIdle:     2 * time.Minute,
            MaxConnectionAge:      5 * time.Minute,
            MaxConnectionAgeGrace: 30 * time.Second,
            Time:                  30 * time.Second,
            Timeout:               10 * time.Second,
        }),

        // Enforce server-side keepalive policy on clients
        grpc.KeepaliveEnforcementPolicy(keepalive.EnforcementPolicy{
            MinTime:             15 * time.Second,
            PermitWithoutStream: true,
        }),

        // Maximum message size: 4MB. Default is 4MB but explicit is better.
        grpc.MaxRecvMsgSize(4 * 1024 * 1024),
        grpc.MaxSendMsgSize(4 * 1024 * 1024),

        // Interceptor chain — order matters:
        grpc.ChainUnaryInterceptor(
            interceptors.UnaryRecovery(logger),          // 1st: catch panics
            interceptors.UnaryLogging(logger),           // 2nd: log every call
            interceptors.UnaryRateLimit(100, 20),        // 3rd: rate limit
            interceptors.UnaryAuth(clients.Auth),        // 4th: validate JWT
        ),
        grpc.ChainStreamInterceptor(
            interceptors.StreamLogging(logger),          // stream logging
        ),
    )

    // ── Register service handlers ─────────────────────────────────────────
    repo := NewPostgresOrderRepository() // your DB layer
    orderpb.RegisterOrderServiceServer(grpcServer, &OrderHandler{
        clients: clients,
        repo:    repo,
    })

    // ── Health check endpoint ─────────────────────────────────────────────
    // Kubernetes liveness/readiness probes use this.
    // grpc_health_v1 is the standard gRPC health protocol.
    healthServer := health.NewServer()
    grpc_health_v1.RegisterHealthServer(grpcServer, healthServer)
    healthServer.SetServingStatus("", grpc_health_v1.HealthCheckResponse_SERVING)

    // ── Reflection (for development tools like grpcurl, Postman) ─────────
    // In production: enable only if explicitly configured, not by default.
    if os.Getenv("GRPC_ENABLE_REFLECTION") == "true" {
        reflection.Register(grpcServer)
        logger.Info("gRPC reflection enabled (dev mode)")
    }

    // ── TCP listener ──────────────────────────────────────────────────────
    addr := getEnv("GRPC_ADDR", ":50052")
    listener, err := net.Listen("tcp", addr)
    if err != nil {
        logger.Fatal("failed to listen", zap.String("addr", addr), zap.Error(err))
    }
    logger.Info("OrderService listening", zap.String("addr", addr))

    // ── Graceful shutdown ─────────────────────────────────────────────────
    // When Kubernetes sends SIGTERM, we have a grace period to finish
    // in-flight requests before being forcefully killed.
    go func() {
        quit := make(chan os.Signal, 1)
        signal.Notify(quit, syscall.SIGTERM, syscall.SIGINT)
        sig := <-quit
        logger.Info("shutting down", zap.String("signal", sig.String()))

        // Mark as not serving — load balancer stops sending new traffic
        healthServer.SetServingStatus("", grpc_health_v1.HealthCheckResponse_NOT_SERVING)

        // Give in-flight requests time to finish (max 30s)
        grpcServer.GracefulStop()
    }()

    if err := grpcServer.Serve(listener); err != nil {
        logger.Fatal("server stopped", zap.Error(err))
    }
}
```

## Chapter 8 — TLS: Encrypting Service-to-Service Communication

In production, all gRPC traffic between services must be encrypted. Even inside a private VPC, you should encrypt inter-service communication — this is called mTLS (mutual TLS) and it means both sides of a connection verify each other's identity.

```go
// shared/tlsutil/tls.go
package tlsutil

import (
    "crypto/tls"
    "crypto/x509"
    "fmt"
    "os"

    "google.golang.org/grpc/credentials"
)

// ServerTLSFromFiles loads the server certificate and key from disk
// and returns gRPC server credentials. The caFile is the certificate
// authority cert used to verify client certificates (mTLS).
func ServerTLSFromFiles(certFile, keyFile, caFile string) (credentials.TransportCredentials, error) {
    // Load this server's certificate and private key
    certificate, err := tls.LoadX509KeyPair(certFile, keyFile)
    if err != nil {
        return nil, fmt.Errorf("failed to load server key pair: %w", err)
    }

    // Load the CA certificate to verify client certificates
    ca, err := os.ReadFile(caFile)
    if err != nil {
        return nil, fmt.Errorf("failed to read CA cert: %w", err)
    }
    caPool := x509.NewCertPool()
    if !caPool.AppendCertsFromPEM(ca) {
        return nil, fmt.Errorf("failed to parse CA cert")
    }

    tlsConfig := &tls.Config{
        Certificates: []tls.Certificate{certificate},
        ClientAuth:   tls.RequireAndVerifyClientCert, // enforce mTLS
        ClientCAs:    caPool,
        MinVersion:   tls.VersionTLS13, // require TLS 1.3 minimum
    }

    return credentials.NewTLS(tlsConfig), nil
}

// ClientTLSFromFiles loads client credentials for mutual TLS.
// The serverName must match the CN in the server's certificate.
func ClientTLSFromFiles(certFile, keyFile, caFile, serverName string) (credentials.TransportCredentials, error) {
    certificate, err := tls.LoadX509KeyPair(certFile, keyFile)
    if err != nil {
        return nil, fmt.Errorf("failed to load client key pair: %w", err)
    }

    ca, err := os.ReadFile(caFile)
    if err != nil {
        return nil, fmt.Errorf("failed to read CA cert: %w", err)
    }
    caPool := x509.NewCertPool()
    if !caPool.AppendCertsFromPEM(ca) {
        return nil, fmt.Errorf("failed to parse CA cert")
    }

    tlsConfig := &tls.Config{
        Certificates: []tls.Certificate{certificate},
        RootCAs:      caPool,
        ServerName:   serverName,
        MinVersion:   tls.VersionTLS13,
    }

    return credentials.NewTLS(tlsConfig), nil
}
```

## Chapter 10 — Dockerfile (Multi-Stage Build)

Every service shares this Dockerfile pattern. The multi-stage build produces a tiny final image — the build stage compiles the Go binary, and the runtime stage contains only that binary and nothing else. This keeps your production image under 20MB instead of 1GB.

```dockerfile
# services/order-service/Dockerfile

# ── Stage 1: Build ─────────────────────────────────────────────────────
FROM golang:1.22-alpine AS builder

WORKDIR /app

# Copy module files first so Docker caches the dependency download layer.
# If go.mod/go.sum don't change, Docker reuses the cached layer and
# skips downloading all modules on every build.
COPY go.mod go.sum ./
RUN go mod download

# Copy the rest of the source
COPY . .

# Build only the order-service binary.
# CGO_ENABLED=0 produces a statically linked binary with no C dependencies.
# -ldflags "-s -w" strips debug symbols, reducing binary size by ~30%.
RUN CGO_ENABLED=0 GOOS=linux go build \
    -ldflags "-s -w" \
    -o /order-service \
    ./services/order-service/

# ── Stage 2: Runtime ───────────────────────────────────────────────────
FROM scratch   
# "scratch" is an empty image — no shell, no OS utilities.
# The binary is the only thing in the container.
# This is the most minimal and secure possible runtime image.

# Copy the compiled binary from the builder stage
COPY --from=builder /order-service /order-service

# Copy CA certificates so the service can make HTTPS/TLS calls
COPY --from=builder /etc/ssl/certs/ca-certificates.crt /etc/ssl/certs/

EXPOSE 50052

ENTRYPOINT ["/order-service"]
```

## Chapter 13 — Best Practice Summary

Every best practice applied in this guide, distilled into a single reference:

```
┌────────────────────────────────────┬──────────────────────────────────────-───┐
│ Practice                           │ Where Applied                            │
├────────────────────────────────────┼────────────────────────────────────-─────┤
│ One .proto per service             │ proto/user/, proto/order/, etc.          │
│ Never edit pb/ files by hand       │ Always regenerate with gen-proto.sh      │
│ Reserve retired field numbers      │ reserved 6, 7; in message blocks         │
│ Use field numbers 1-15 for hot     │ id, name, email always get low numbers   │
│   fields                           │                                          │
│ One DB per service                 │ Separate postgres containers per service │
│ Connection pool per target service │ ConnectionManager singleton              │
│ One conn reused for all RPCs       │ grpc.Dial() called once at startup       │
│ Interceptor chain (not ad-hoc)     │ ChainUnaryInterceptor in server setup    │
│ Recovery always outermost          │ First interceptor in the chain           │
│ Auth via interceptor, not handler  │ UnaryAuth interceptor                    │
│ User ID in context, not re-parsed  │ UserIDFromContext() helper               │
│ Propagate context deadlines        │ ctx passed to all downstream calls       │
│ Child timeout per operation        │ context.WithTimeout(ctx, 10s)            │
│ Non-critical work in goroutine     │ Notification send after response         │
│ Compensating transactions          │ Release inventory if payment fails       │
│ Graceful shutdown                  │ grpcServer.GracefulStop() on SIGTERM     │
│ Health check endpoint              │ grpc_health_v1 registered on every svc   │
│ Keepalive on both sides            │ Client + Server keepalive params         │
│ Reflection only in dev             │ GRPC_ENABLE_REFLECTION env var gate      │
│ mTLS in production                 │ tlsutil package                          │
│ Structured logging                 │ zap.Logger, not fmt.Println              │
│ Per-user rate limiting             │ UnaryRateLimit with user_id key          │
│ Multi-stage Docker build           │ builder → scratch image                  │
│ Addresses from environment vars    │ getEnv() with fallback                   │
│ Fail fast on startup               │ Dial all services before Serve()         │
└────────────────────────────────────┴─────────────────────────────────────-────┘
```
